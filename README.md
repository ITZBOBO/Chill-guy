# 🐾 The Chill Guy

> *Just vibing through life, one deep breath at a time. No pressure. No rush. Just flow.*

A single-page website built for the unbothered. Inspired by the internet’s favourite nonchalant dog, The Chill Guy is a lo-fi, warm-toned landing page that radiates calm energy from every pixel.

-----

## ✨ Features

- **CSS Character** — A fully hand-crafted Chill Guy illustration built entirely in CSS, complete with a slow, looping head-bob animation and hands in pockets
- **Scrolling Marquee** — An infinite ticker of certified chill phrases: *“It is what it is”*, *“We move”*, *“Big chilling”* and more
- **The Philosophy** — Six life mantras that scroll-reveal with staggered animations as you read
- **Vibe Check Dashboard** — Animated progress meters reporting live chill stats (Relaxation: 94% · Stress: 3% · Nap Readiness: 100%)
- **Chill Curriculum** — Six hover cards covering the essential chill practices: deep breathing, pocket walks, sacred beverages, and more
- **Custom Cursor** — A rust-toned dot that grows on interactive elements
- **Grain Texture Overlay** — Subtle noise layer for that warm, analog feel
- **Scroll-reveal Animations** — IntersectionObserver-powered entrance animations throughout

## 🚀 Usage

Zero dependencies. Zero build step. Just open it.

```bash
# Clone or download the file, then:
open the-chill-guy.html
```

Or drop it anywhere that serves static HTML — GitHub Pages, Vercel, Netlify, a USB stick.

-----

## 🗂 File Structure

```
the-chill-guy.html   ← the whole thing, self-contained
README.md            ← you are here
```

All styles, scripts, and the CSS character live in a single file. Google Fonts (`Playfair Display` + `DM Mono`) are loaded via CDN — an internet connection is needed for correct typography.
